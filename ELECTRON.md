# Ejecutar el juego original con Electron

El HTML, CSS, JavaScript y README del juego se conservan como estaban en la versión original.

Para abrir la aplicación en Windows, ejecutá `dist/Snake-Game-1.0.0-Windows.exe`. No necesita instalación.

Para trabajar en el proyecto, necesitás Node.js y npm:

```sh
npm ci
npm start
```

Para volver a generar el ejecutable portable:

```sh
npm run dist
```

La aplicación se guarda en `dist/`. El ejecutable no tiene firma digital.
